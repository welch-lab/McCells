# Processed Data

This directory contains processed data and cached ontology objects generated by `run_preprocessing.py`.

## Files

### `ontology.pkl`

A cached `pronto.Ontology` object representing the Cell Ontology (CL), generated by `src/data_pipeline/cache_ontology.py`.

### Run-Specific Folders

Folders are named `{CL_ID}_{MM-DD}` where `CL_ID` is the root ontology term (colon removed) and `MM-DD` is the preprocessing date. Files inside are prefixed with the full date `YYYY-MM-DD`.

### Artifact Descriptions

- `*_marginalization_df.csv`: Internal nodes x leaf nodes matrix (1 if leaf is descendant of internal node).
- `*_parent_child_df.csv`: All cell types x internal nodes ground truth ancestor matrix.
- `*_exclusion_df.csv`: All cell types x internal nodes masking matrix.
- `*_mapping_dict_df.csv`: Mapping from CL IDs to integer indices.
- `*_leaf_values.pkl`: Pickled list of effective leaf CL IDs.
- `*_internal_values.pkl`: Pickled list of internal CL IDs with children.
